# Custom Command: /explain_this_file

**Description:**
Explain the purpose and contents of the file `$1` in simple, easy to understand language. It helps you grasp what a file does without needing to understand technical details.

**Action1:**
Connect to Jira

**Action2:**
Get relevant information from the Jira ticket $2
